**发布日期：2026-10-22。** Barn 0.x 版本沿用 GitHub 预发布频道。

Barn 0.9.1 升级 Go 工具链与依赖，并将 Mac 原生组件统一命名为 **Barn.app**。
CLI 命令、清单格式、镜像目录和已有虚拟机的状态路径与 0.9.0 保持兼容。

## 变更

- 源码、CI 与发行制品统一使用 **Go 1.27.3**。`go.mod` 中的直接、间接及依赖测试
  模块均更新至截至 2026-10-22 核实的最新稳定版本，其中包括
  `golang.org/x/crypto` v0.58.0、`x/net` v0.61.0、`x/sys` v0.49.0、
  `x/term` v0.47.0 和 `x/text` v0.43.0。
- Mac 原生应用从 `Barn Mac.app` 改名为 **Barn.app**，应用标识为
  `com.pgsty.barn`，菜单名称同步为 Barn。新 CLI 继续识别旧的 `Barn Mac.app`。
  原生协议版本仍为 2，虚拟机状态仍在 `~/.barn/mac`。
- 独立 Mac runner 使用 hardened runtime 签名，证书签名请求安全时间戳。
  原生载荷除校验版本、提交和文件摘要外，还校验 App 名称、标识与可执行文件。
  安装器和 Homebrew 模板同步使用新路径。
- 构建与检查工具升级为 GoReleaser 2.18.3、独立 nFPM 2.48.0、Syft 1.55.0、
  Staticcheck 2026.2.2、deadcode 0.52.0、golangci-lint 2.15.0 和 govulncheck 1.9.0。
  GoReleaser 上游内嵌的 nFPM 为 2.47.0。GitHub Actions 继续按提交固定版本，
  依赖许可证清单与新版本保持一致。

## 升级

在下载安装器中显式指定 **0.9.1**，或升级 Homebrew 配方 / Linux 软件包。
GitHub 的 `releases/latest` 不选择预发布版本，具体命令见
[安装指南](/zh/docs/start/installation/)。

替换原生组件前先停止 Mac 虚拟机。CLI、hosts helper 与 App 应来自同一次构建，
一并更新。0.9.0 CLI 不会按新名称发现 `Barn.app`。桌面窗口位置改用
`~/Library/Preferences/com.pgsty.barn.plist`，原窗口位置可能重置；虚拟机磁盘、
凭据和配置仍保存在 `~/.barn/mac`。此次升级不需要重建虚拟机或更新镜像目录。

0.9.1 提供 macOS / Linux 的 arm64、amd64 CLI 与 hosts helper 归档，以及 Linux
DEB/RPM 软件包。**本次发行资产不包含 `Barn.app`。** Mac 原生组件继续作为源码预览：
使用 Go 1.27.3 和 Xcode 27，从 `v0.9.1` 标签一并构建 CLI 与 App，详见
[Mac 指南](/zh/docs/start/macos/#install)。本次不分发已公证的 Mac 原生载荷。

[发布检查清单](https://github.com/pgsty/barn/blob/v0.9.1/docs/release-0.9.1.md)分别记录本地验证、托管 CI、真实虚拟机、
签名与发布状态。
