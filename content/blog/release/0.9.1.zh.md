**发布日期：2026-10-22。** Barn 0.x 版本通过 GitHub 预发布渠道分发。若需直接通过 Apple Silicon 发行包或 Homebrew 安装已签名公证的 `Barn.app`，请升级至最新的 **[Barn 0.9.2](../0.9.2/)**。

Barn 0.9.1 升级了 Go 工具链与依赖模块，并将 Mac 原生组件统一命名为 **Barn.app**。CLI 命令、清单格式、镜像目录与已有虚拟机状态路径均与 0.9.0 保持兼容。

[安装 Barn](/zh/docs/start/installation/) · [下载 0.9.1](https://github.com/pgsty/barn/releases/tag/v0.9.1) · [发布检查清单](https://github.com/pgsty/barn/blob/v0.9.1/docs/release-0.9.1.md)

## 变更

- 源码构建、CI 与发行制品统一升级至 **Go 1.27.3**。`go.mod` 中的直接、间接及依赖测试模块均更新至截至 2026-10-22 的最新稳定版，包括 `golang.org/x/crypto` v0.58.0、`x/net` v0.61.0、`x/sys` v0.49.0、`x/term` v0.47.0 和 `x/text` v0.43.0。
- Mac 原生应用由 `Barn Mac.app` 改名为 **Barn.app**，Bundle Identifier 更新为 `com.pgsty.barn`，菜单文案同步改为 Barn。0.9.1 CLI 仍兼容查找旧版 `Barn Mac.app`。原生协议版本保持为 2，虚拟机状态目录仍为 `~/.barn/mac`。
- 独立 Mac runner 采用 hardened runtime 签名，使用证书签名时自动请求安全时间戳。原生载荷校验除核对版本号、Git 提交与文件摘要外，还会校验 App 名称、Bundle Identifier 与主可执行文件。安装脚本与 Homebrew 配方模板均已同步至新路径。
- 构建与静态检查工具升级至 GoReleaser 2.18.3（内置 nFPM 2.47.0）、独立 nFPM 2.48.0、Syft 1.55.0、Staticcheck 2026.2.2、deadcode 0.52.0、golangci-lint 2.15.0 和 govulncheck 1.9.0。GitHub Actions 继续按提交哈希固定版本，依赖许可证清单已与新工具链同步。

## 升级

使用下载安装脚本时请显式指定 **0.9.1**，或直接升级 Homebrew 配方与 Linux 软件包（具体命令见[安装指南](/zh/docs/start/installation/)）。

替换原生组件前请先停止正在运行的 Mac 虚拟机，并将同一次构建产出的 CLI、hosts helper 与 App 一并更新（0.9.0 CLI 仅识别旧名称 `Barn Mac.app`）。桌面窗口位置改用 `~/Library/Preferences/com.pgsty.barn.plist` 存储，首次打开时窗口位置可能重置；`~/.barn/mac` 下的虚拟机磁盘、凭据和配置保持不变，无需重建虚拟机或更新镜像目录。

0.9.1 发行包提供 macOS 与 Linux（`arm64` / `amd64`）的 CLI 与 hosts helper 归档及 Linux DEB/RPM 软件包。如需使用 `barn mac`，请使用 Go 1.27.3 和 Xcode 27 从 `v0.9.1` 标签一并构建 CLI 与 `Barn.app`，详见 [macOS 虚拟机指南](/zh/docs/start/macos/#install)。

从 `v0.9.1` 标签单独构建 CLI：

```bash
BARN_VERSION=0.9.1 make build
bin/barn version
```

构建、CI、虚拟机验收与签名步骤详见 [0.9.1 发布检查清单](https://github.com/pgsty/barn/blob/v0.9.1/docs/release-0.9.1.md)。
