**Released on 2026-10-22.** Barn 0.x releases are published via GitHub's pre-release channel. For the latest release with a signed and notarized `Barn.app` in the Apple Silicon archive and Homebrew formula, see **[Barn 0.9.2](../0.9.2/)**.

Barn 0.9.1 updates the Go toolchain and dependencies and completes the native Mac app rename to **Barn.app**. CLI commands, inventory format, image catalog, and existing VM state paths remain compatible with 0.9.0.

[Install Barn](/docs/start/installation/) · [Download 0.9.1](https://github.com/pgsty/barn/releases/tag/v0.9.1) · [Release checklist](https://github.com/pgsty/barn/blob/v0.9.1/docs/release-0.9.1.md)

## Changes

- **Go 1.27.3** is the baseline for source builds, CI, and release artifacts. All modules required by `go.mod`—including indirect and dependency-test modules—are updated to their latest stable versions as of 2026-10-22, including `golang.org/x/crypto` v0.58.0, `x/net` v0.61.0, `x/sys` v0.49.0, `x/term` v0.47.0, and `x/text` v0.43.0.
- **Barn.app** replaces the `Barn Mac.app` bundle name, using bundle identifier `com.pgsty.barn` and updated Barn menu labels. The 0.9.1 CLI continues to discover older `Barn Mac.app` bundles if present. Native protocol version 2 and `~/.barn/mac` are unchanged.
- The standalone Mac runner uses hardened-runtime signing and requests a secure timestamp when signing with a Developer ID certificate. Payload validation checks the app bundle name, identifier, and executable alongside its version, commit, and content digests. Both the installer and Homebrew template use the new app path.
- Build and verification tools are updated to GoReleaser 2.18.3 (with bundled nFPM 2.47.0), standalone nFPM 2.48.0, Syft 1.55.0, Staticcheck 2026.2.2, deadcode 0.52.0, golangci-lint 2.15.0, and govulncheck 1.9.0. GitHub Actions remain pinned by commit, and dependency-license inventories match the updated modules and toolchain.

## Upgrade

Pin **0.9.1** explicitly when running the download installer, or upgrade via the Homebrew formula or Linux package manager (see the [installation guide](/docs/start/installation/)).

Before replacing the native Mac component, stop running Mac VMs and upgrade the CLI, hosts helper, and app together from the same build—the 0.9.0 CLI only looks for the old `Barn Mac.app` bundle name. Desktop window positions now use `~/Library/Preferences/com.pgsty.barn.plist`, so saved window coordinates may reset once. VM disks, credentials, and configuration under `~/.barn/mac` are preserved without recreating VMs or refreshing image catalogs.

The 0.9.1 release assets include macOS and Linux (`arm64` / `amd64`) CLI and hosts-helper archives plus Linux DEB and RPM packages. To use `barn mac`, build the CLI and `Barn.app` together from tag `v0.9.1` with Go 1.27.3 and Xcode 27 as described in the [macOS guide](/docs/start/macos/#install).

To build the CLI alone from tag `v0.9.1`:

```bash
BARN_VERSION=0.9.1 make build
bin/barn version
```

See the [0.9.1 release checklist](https://github.com/pgsty/barn/blob/v0.9.1/docs/release-0.9.1.md) for the build, CI, VM acceptance, and signing steps.
