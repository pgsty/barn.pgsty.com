> 本页为历史发布记录，名称统一为 Barn。旧版发行附件已下线，安装请使用[当前指南](/zh/docs/start/installation/)。

Barn 0.2.0 是已由 0.3.0 取代的公开预发布版，属于 1.0 之前的版本。它保留 0.1.0 引入的 Pigsty 清单和磁盘部署格式，
并修复最终真机重放中发现的网络检查与选定节点收敛问题。

## 主要变化

- `10.0.0.0/8` 等较宽的 VPN 排除路由不再误拦 Barn 自有的 `10.10.10.0/24`。
  外部路由相同或更具体、接口重叠、地址已占用或自有路由缺失时，Barn 仍会拒绝继续。
- `barn up <node>` 只下载并准备选中的节点。清单中尚未写入状态的期望节点显示为 `absent`。
  SSH/hosts/客机配置、UUID/端口分配、生命周期与持久盘校验只使用已提交的节点集合。
  清单仍保留后续扩容所需的节点定义。
- 新客机写入 `# barn-deployment-host`；添加当前 hosts 行前，会同时清理该标记
  与 0.1.0 发布过的 `# barn-project-host`。
- 0.2.0 合并了未发布中间版本的命令取消、结构化输出、确认、`reload`、诊断脱敏、安装器保留策略与依赖图精简改进。

## 真机与发布证据

发行源码提交在 MonoProxy 在线时完成了 macOS arm64/HVF 重放。
选点创建 `u24-1`、SSH、停止后启动、增量创建已缓存的 `el9-1` 均通过。
两节点 SSH、五个明确标为缺席的节点和整套销毁也均通过。
在 Ubuntu 26.04 amd64/KVM 上，该版本 Linux 二进制以只读方式审计了一套现存四节点部署，并进入控制客机。

本地 `make check`、源码 CI 与完整打包工作流均通过。
标签工作流构建四平台归档、amd64/arm64 DEB 与 RPM、SPDX SBOM、Homebrew 配方、安装器、校验和及发布元数据。
GitHub Actions 将通过验证的 CI 产物上传到草稿发布，检查后再公开。此次发布不附加应用签名或来源证明包。

签名镜像目录的修订号仍为 `2026082903`，包含 9 个系列与 27 个分架构产物。
默认仓库继续使用 `https://repo.pigsty.cc/barn`；`repo.pgsty.com/barn` 是独立验收
通过的源站/备用入口，不是编译默认值。

## 安装或升级

从 [Barn 0.2.0 GitHub 发布](https://github.com/pgsty/barn/releases/tag/v0.2.0)
下载 `install.sh` 与对应构件：

```bash
chmod +x install.sh
BARN_VERSION=0.2.0 ./install.sh
barn version
barn doctor
```

0.1.0 的部署状态可直接读取。在虚拟机运行时执行一次 `barn status`，可补齐发布前记录的进程创建身份。
现有客机在重建时采用新的 `/etc/hosts` 标记。

Barn 尚未达到 1.0，因此 GitHub 会把 0.2.0 标为预发布。
