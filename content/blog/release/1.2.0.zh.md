**发布准备，更新于 2026-11-12。** Barn 1.2.0 目前为本地候选版本，尚未发布。当前稳定版为 [Barn 1.1.0](/zh/blog/release/1.1.0/)。

## 从 1.1.0 升级 {#upgrade-from-110}

候选版本将未指定的 Linux CPU/内存默认值从 2 vCPU / 4 GiB 改为 1 vCPU / 2 GiB。读取未填写这两个字段的旧清单时，新默认值也会生效。若要保留原规格，请在 `all.vars` 中显式设置 `vm_cpu: 2` 和 `vm_mem: 4GiB`，保留已有的主机级覆盖，并在应用变更前查看 `barn plan`。已有虚拟机在执行资源变更操作之前仍保持已应用的规格。根盘和数据盘默认容量分别仍为 64 GiB 和 128 GiB。

## 虚拟机资源 {#vm-resources}

候选版本在镜像与架构选择之外新增 `--cpu/-C`、`--mem/-M`、`--scale/-S` 和 `--disk/-D`。对应的 `BARN_*` 环境变量提供默认值，命令行参数优先；生成主机清单时会保存资源基值。计划、验证、状态与生命周期输出使用 `2c4g` 等 `SPEC` 标签展示生效资源；JSON 包含数值、基值、倍率与输入来源。

`resize --disk/-D` 支持扩容现有根盘。Barn 先停止 QEMU，再扩大磁盘，并在客机内核验最后一个普通分区与 ext4/XFS 文件系统。扩容阶段会持久化，便于中断后继续；缩容与不支持的根盘布局会被拒绝。实现与回归测试位于 `cmd/barn/vm_inputs.go`、`cmd/barn/vm_inputs_test.go`、`internal/private/root_resize.go` 和 `internal/private/root_resize_test.go`。

## 生命周期并发 {#lifecycle-concurrency}

`--parallel/-p` 控制 Linux 生命周期命令的并发度。默认值为逻辑 CPU 数减二，最小为一；零表示并发处理全部选中节点，正整数表示并发上限。重试命令保留显式覆盖值。相关测试位于 `internal/private/concurrency_test.go` 和 `cmd/barn/lifecycle_parallel_test.go`。

## 清单主机名 {#inventory-host-names}

本次审查的工作区新增 `all.vars.vm_hosts` 和 `barn hosts install -f INVENTORY`，这些改动仍需纳入发布提交。它们将额外的宿主服务域名与节点名合并，支持在创建虚拟机之前发布解析记录。先用 `barn hosts install -f pigsty.yml --json` 预览，再用 `barn hosts install -f pigsty.yml --yes` 应用；省略 `-f` 时继续使用已应用的节点名。相同映射忽略大小写后合并，地址冲突则报错。这些宿主解析记录不改变虚拟机身份或客机配置，详见[额外 hosts 映射](/zh/docs/reference/configuration/#local-hosts)。

## 依赖与打包 {#dependencies-and-packaging}

2026-11-11 已逐项核对全部 19 个显式 Go 模块依赖的最新稳定版本，本次更新以下版本锁定：

| 组件 | 原版本 | 候选版本 |
| --- | --- | --- |
| Go | 1.27.3 | 1.27.4 |
| `golang.org/x/sys` | 0.49.0 | 0.50.0 |
| `golang.org/x/term` | 0.47.0 | 0.48.0 |
| `golang.org/x/text` | 0.43.0 | 0.44.0 |
| `github.com/klauspost/compress` | 1.20.3 | 1.20.4 |
| GoReleaser | 2.18.3 | 2.20.1 |
| GoReleaser 内置 nFPM | 2.47.0 | 2.48.0 |
| Syft | 1.55.0 | 1.57.1 |

其他模块依赖、独立 nFPM、质量检查工具与 GitHub Actions 已使用最新稳定版本。CI 同步采用新版工具链与核验后的 Syft 下载摘要，依赖许可证清单与 CLI、helper 实际链接的模块一致。版本依据见本地提交 `6ab0cd5` 的 `packaging/toolchain.env` 与 `go.mod`；本次核对的远端 main 仍指向 1.1.0。

nFPM 2.48 会在 RPM 载荷的文件与目录中保留 `SOURCE_DATE_EPOCH`。`packaging/verify-linux-packages.sh` 已改为要求该时间戳，替代旧打包器使用的 Unix epoch 零值。真实 RPM 样例已核验包头与解包后载荷的时间戳，完整打包 snapshot 也已通过更新后的检查。

## 镜像目录 {#image-catalog}

候选版本内置签名目录 revision `2026110502`。2026-11-11 执行的 `make catalog-check` 已对两个官方源验签，在全新的临时数据目录中分别激活目录，确认其与内置目录逐字节一致，并检查全部 17 个 stable 制品的可达性与大小。默认镜像为宿主原生架构的 Ubuntu 24.04。

## 本地验证 {#local-validation}

[2026-11-12 发布准备核对](/zh/blog/design/release-1-2-0-readiness/)补充了包含原生 App 的完整 snapshot 打包、Linux/KVM 失败恢复验收与 15 阶段 Mac 生命周期检查，并列明最终发布提交和签名制品的剩余门禁。

2026-11-11 的验证基于提交 `1e24768` 之上的修改工作树，使用锁定的工具链：

- `make check` 已通过，覆盖单元与竞态测试、静态分析、四平台交叉编译、安装器与镜像流水线检查，以及依赖许可证清单。
- `make mac-native-test` 的原生组件测试已通过。
- `make release-snapshot SNAPSHOT_DIST=.goreleaser-refresh-1.2.0-20261111` 已通过压缩包、DEB/RPM、SPDX、校验和、时间戳、配套 helper 与包内容一致性检查。现有 snapshot 规则根据最近的已发布标签生成 `1.1.1-next`，本地开发二进制报告 `1.2.0-dev.1`。snapshot 验证覆盖 CLI/helper 压缩包与 Linux 软件包，正式 Mac 制品沿用签名载荷发布流程。
- 候选二进制执行 `barn update --repo https://repo.pigsty.io/barn`，在全新的临时 `BARN_HOME` 中激活官方签名目录，并确认其字节与内置目录一致。
- 文档生产构建与包含草稿的构建均已通过内链与资源检查。

`govulncheck` 在已导入包与可达符号中均未发现漏洞。模块级报告包含 `golang.org/x/crypto/openpgp` 的 [GO-2026-5932](https://pkg.go.dev/vuln/GO-2026-5932)，Barn 未导入该包。

## 构建候选版本 {#build-the-candidate}

使用 Go 1.27.4，在准备好的源码工作树中执行：

```bash
BARN_VERSION=1.2.0-dev.1 make build
./bin/barn version
```

已发布的安装器仍选择 1.1.0。1.2.0 制品公开后，再补充正式发布日期与下载方式。
