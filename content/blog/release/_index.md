This section lists changes, upgrade notes, and installation links for each Barn release.

Current version: **[Barn 0.9.1](0.9.1/)**, released on 2026-10-22.

Current published version: **[Barn 0.9.0](0.9.0/)** (GitHub pre-release).

## Release history

| Version | Date | Main changes |
| --- | --- | --- |
| [0.9.1](0.9.1/) | 2026-10-22 | Go 1.27.3, dependency updates, and Barn.app naming and signing |
| [0.9.0](0.9.0/) | 2026-09-30 | Native macOS machines, consistent errors, and interrupted-operation recovery |
| [0.8.0](0.8.0/) | 2026-09-21 | Host recovery, independent node failures, and refreshed images |
| [0.7.0](0.7.0/) | 2026-09-16 | Simpler first runs and automatic guest recovery |
| [0.6.0](0.6.0/) | 2026-09-05 | Ubuntu 24.04 defaults and improved plan, expansion, and recreation commands |
| [0.5.0](0.5.0/) | 2026-09-03 | Explicit disposal, repository selection, and reproducible images |
| [0.4.0](0.4.0/) | 2026-09-02 | One-command setup, working data disks, and consistent output |
| [0.3.0](0.3.0/) | 2026-09-02 | Explicit catalog updates and actionable readiness diagnostics |
| [0.2.0](0.2.0/) | 2026-09-01 | Selected-node convergence and release integrity |

The source repository also retains the [0.1.0 release-note draft](https://github.com/pgsty/barn/blob/54315029d4a8d3ace7b4f7250d0381598f2d61dc/.github/releases/0.1.0.md). Earlier development records cover
the [2026-08-24 snapshot](development-snapshot-20260824/) and the
[2026-08-25 RC6 candidate](rc6-owner-scoped-20260825/).

Historical notes use Barn naming while preserving original dates, version
numbers, changes, and validation results. Old release downloads are no longer
available. See the [validation history](/docs/about/history/) for the dated
test evidence and the [installation guide](/docs/start/installation/) for
the current release.
