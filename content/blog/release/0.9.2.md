**Released on 2026-10-30.** Barn 0.x releases use GitHub's pre-release channel.

Barn 0.9.2 includes the complete native macOS guest runtime in the Apple Silicon download and Homebrew installation. You can create Linux and macOS VMs after installing a single package, without installing Go or Xcode.

[Install Barn](/docs/start/installation/) · [Download 0.9.2](https://github.com/pgsty/barn/releases/tag/v0.9.2) · [Source release notes](https://github.com/pgsty/barn/blob/v0.9.2/.github/releases/0.9.2.md)

## Changes

- The Darwin arm64 archive contains `barn`, `barn-hosts-helper`, and `Barn.app` from the same source commit. All three executables use Developer ID signatures and are submitted together for Apple notarization; the app carries a stapled ticket and passes Gatekeeper assessment.
- `brew install pgsty/infra/barn` installs the CLI, QEMU, helper, and native app. The CLI discovers the app under Homebrew's `libexec`. macOS guests require Apple Silicon, macOS 27+, and a logged-in desktop session.
- The helper is signed before its final SHA-256 is embedded in the CLI. Packaging checks the pair again after attaching the native payload to the release archive.
- `ssh`, `exec`, `mac ssh`, and `mac exec` require `--` before remote commands. SSH passes a command line to the guest shell; exec preserves individual arguments. Use `sh -c` with exec for pipelines or redirection.
- Linux arm64/amd64 and Intel macOS continue to ship the CLI and helper for QEMU Linux guests.

## Install and use

```bash
brew install pgsty/infra/barn
barn version

# Linux guest
barn up
barn ssh
barn exec meta -- uname -a

# macOS guest on Apple Silicon / macOS 27+
barn mac doctor
barn mac up mac1
barn mac open mac1
barn mac ssh mac1
```

The first macOS VM downloads Apple's restore image and prepares a reusable base installation. Supply an existing compatible IPSW with `barn mac setup --ipsw PATH` to use a local restore image.

## Upgrade

Stop running Mac VMs before replacing the app, then run `brew update` and `brew upgrade pgsty/infra/barn`. VM disks and configuration remain in `~/.barn`; no recreation is required. Update older SSH/exec scripts to use `--` and pass exec programs and arguments separately.

For the download installer, specify `BARN_VERSION=0.9.2` because GitHub's `releases/latest` endpoint does not select pre-releases. The release includes four platform archives, Linux DEB/RPM packages, SPDX inventories, checksums, the installer, and the generated Homebrew formula. `release.json` records the exact source commit and pinned build tools.

Path, sharing, node-selection, and limit improvements implemented after this release are documented under [Unreleased Changes](/docs/about/unreleased/).
