**发布日期：2026-09-30。** Barn 0.9.0 用同一套命令行工具管理 Linux 实验环境与原生 macOS 虚拟机，并改进了错误诊断与中断操作恢复。最新稳定体验请参见 **[Barn 0.9.2](../0.9.2/)**。

[安装指南](/zh/docs/start/installation/) · [下载 0.9.0 发行包](https://github.com/pgsty/barn/releases/tag/v0.9.0) · [完整变更记录](https://github.com/pgsty/barn/blob/v0.9.0/CHANGELOG.md)

## Apple Silicon 上的 macOS 虚拟机

`barn mac` 可创建命名的 macOS 27 虚拟机，支持原生桌面窗口、SSH、共享目录与文本剪贴板。首台机器从经过校验的 Apple 恢复镜像安装共享黄金母盘，后续机器通过 APFS 写时复制克隆母盘，各自拥有独立的可写磁盘、登录凭据与私有子网。

```bash
barn mac up
barn mac open
barn mac ssh
```

Mac 客机需要 Apple Silicon、macOS 27+ 以及使用 Xcode 27 从发行标签构建的原生应用包（构建步骤见 [macOS 指南](/zh/docs/start/macos/#install)）。受 Apple Virtualization.framework 与软件许可限制，每台 Mac 最多同时运行两台 macOS 虚拟机（含其他工具启动的实例）。Mac 虚拟机状态独立存放在 `~/.barn/mac` 下，不受 Linux 环境 `destroy` 或 `purge` 影响。

## 更顺畅的 Linux 环境恢复

重复执行 `barn up` 即可接续未完成的初始化：首次启动失败后修正配置可直接原位重试，中断的 `destroy` 也能继续完成。宿主机重启后，即便原 QEMU PID 被操作系统分配给其他无关进程，Barn 也能通过进程启动时间识别原虚拟机已停止，绝不会误杀无关进程。

并发修改命令最多等待十分钟并提示当前持有部署锁的操作，只读状态查询与 SSH 连接在此期间依然可用。执行计划现在会逐项列出节点的数据盘（包括默认挂载到 `/data` 的 128 GiB 数据盘）。

## 指向下一步的诊断信息

配置校验错误会定位具体规则、字段值与行号，并自动提示拼写近似的 `vm_*` 字段名。外部命令执行失败时保留 `stderr` 末尾的关键报错信息；JSON 错误输出统一使用固定 `error` 分类，并按需附带 `reason` 与 `next` 字段。

宿主环境准备在请求 `sudo` 权限前会先列出待安装的软件包与网络变更。若 `~/.ssh/config` 是由 dotfile 工具管理的符号链接，Barn 会保持原文件不动，并打印需手动添加的 `Include` 指令。

## 更新的 Linux 镜像

内置镜像目录升级至 **2026093001**，涵盖 **9 个发行版系列、41 个镜像产物**。Debian 12/13 与 Rocky Linux 8/9 采用经过 Barn 规范化的镜像：Debian 预装离线 XFS 工具并生成 `en_US.UTF-8`（默认区域设置仍为 `C.UTF-8`）；Rocky Linux 8 启用自带的 `chronyd` 服务，并在构建阶段完成 SELinux 标签写入，省去首次启动全盘重打标签的耗时。Ubuntu 保留 Canonical 官方镜像字节，默认客机系统仍为 Ubuntu 24.04（`u24`）。

```bash
barn image list
barn update
```

`barn update` 仅刷新本地 Linux 镜像目录，不会升级 `barn` 二进制或替换已有虚拟机磁盘。

## 升级注意事项

- 命令行工具为 `barn`，默认配置文件名为 `barn.yml`，状态目录为 `~/.barn`，环境变量前缀统一为 `BARN_*`。
- 移除了 `rm` 别名；如需彻底删除整套 Linux 部署（含持久数据盘与密钥），请显式运行 `barn purge`。
- JSON 错误结构调整：`recreate_required` 与 `nodes_removed` 归入 `error: "conflict"` 的 `reason` 字段，`resource_conflict` 简化为 `resource`，缺少配置文件或未知镜像统一返回退出码 `2`（`usage`），详见[退出码参考](/zh/docs/reference/cli/#退出码)。
- `stop` 和 `start` 保留全部磁盘，`recreate` 替换根盘与非持久数据盘。数据盘在恢复过程中的自动重建规则见[存储指南](/zh/docs/start/storage/)。
