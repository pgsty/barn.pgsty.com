Barn 0.3.0 是已由 0.4.0 取代的公开预发布版，属于 1.0 之前的版本。它移除隐式镜像目录刷新，并按节点报告客机初始化失败及处理方法。
它还简化了 CLI，同时保留 Pigsty 清单与固定 IP 部署模型。

## 变化

- `up`、`plan` 与普通 `image` 命令只使用一份当前本地镜像目录快照，绝不隐式获取
  镜像目录元数据。`barn update` 显式获取配置仓库；`image sync` 激活精确 URL 或文件。
- 客机初始化以原子方式记录失败阶段。操作部分失败时，结果会列出每个失败节点、阶段与错误。
  就绪失败会提示使用 `barn logs <node>`。
- 已运行客机可在不重启 QEMU 的情况下复查。生命周期部分失败后，SSH 客户端配置仍会
  根据全部已提交节点重建。
- Netplan 按确定性 MAC 匹配且不再重命名接口。`vm_disks[].fs: auto` 优先 XFS，必要时
  回退到 ext4。
- 删除冗余 `ss` 命令与含义模糊的根/参数短写；`image reset` 取代
  `reset-manifest`，旧名称仍是别名。

## 安装或升级

从 [Barn 0.3.0 GitHub 发布](https://github.com/pgsty/barn/releases/tag/v0.3.0)
下载安装器与资产：

```bash
curl -fLO https://github.com/pgsty/barn/releases/download/v0.3.0/install.sh
chmod +x install.sh
BARN_VERSION=0.3.0 ./install.sh
barn version
barn doctor
```

同一预发布附带 Homebrew 配方与 amd64/arm64 DEB/RPM 软件包。现有 0.1/0.2
部署与镜像目录状态仍可读取；镜像目录刷新从本版本开始始终显式。
