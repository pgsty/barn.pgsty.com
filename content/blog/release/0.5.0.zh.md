Barn 0.5.0 是已由 0.6.0 取代的公开预发布版，属于 1.0 之前的版本。它为一次性实验环境加入明确的清理命令，并允许操作者选择仓库地域。
它还为后续官方客机镜像提供可复现的构建流程。Pigsty 清单约定、部署状态格式与内嵌镜像目录修订号 `2026082903` 均未变化。

## 变化

- `barn purge`（别名 `barn rm`）无需确认，删除完整部署、持久数据盘、
  部署密钥与状态，以及默认 SSH 片段；已校验镜像缓存与宿主全局网络仍然保留。
  没有部署时，重复执行也会成功。遗留节点产物的身份无法确认时，Barn 仍会拒绝继续。
- 发布二进制默认使用 `https://repo.pigsty.io/barn`。仅有长参数的 `--mirror` 选择
  `https://repo.pigsty.cc/barn`；优先级依次为 `--repo`、`--mirror`、`BARN_REPO`、
  全球默认仓库。两个官方根都保持规范的签名镜像目录信任。
- 镜像目录中的上游 URL 只用于溯源，不再用于下载回退。
  选定仓库必须包含镜像目录指定的准确 qcow2 文件。否则，下载会失败，并提示显式选择其他仓库或导入本地镜像。
- 源码新增 Debian 12/13、Rocky Linux 8/9 在 amd64/arm64 上的摘要锁定离线构建器。
  它记录准确软件包闭包、SBOM、来源记录与 `testing` 清单文件，并可组装未签名候选仓库，
  留待真机冒烟测试与签名审查。
- 固定的源码/发布工具链升级到 Go 1.27.1、GoReleaser 2.18.0、golangci-lint 2.13.2
  与当前选定的 Go 模块版本。

## 镜像边界

八目标矩阵补齐了客机前置条件。Debian 12/13 加入显式使用 XFS 数据盘所需的 XFS 用户态工具。
Rocky Linux 8 加入 `/usr/bin/python3`，修正 SSH 配置片段的包含规则，并清理网卡命名状态。
Rocky Linux 9 同样清理旧网络状态。

这些修改只提供候选镜像的构建输入，尚未发布新的镜像目录产物。
每份结果都必须完成真机启动/就绪冒烟测试、双构建比较、生产签名、上传和镜像目录发布。
完成这些步骤前，结果保持未签名和 `testing` 状态。

## 升级与处置

从 0.4.0 升级无需迁移状态、清单或镜像目录，现有缓存镜像仍可使用。新的下载默认走
全球仓库，除非用 `--mirror`、`--repo` 或 `BARN_REPO` 选择其他根。

`purge` 刻意设计为无交互操作，会不可逆删除部署磁盘与密钥。若要保留持久盘或只
删除部分节点，请继续使用带确认的 `barn destroy`。

## 验证边界

发布源码提交 `fc85b65ff6a24b0933b56ae1179be9ada2ba91b1` 通过完整本地源码检查。
检查包括模块与 Shell 检查、单测、竞态测试、Vet、Staticcheck、deadcode、errcheck、`govulncheck` 和四目标构建。
模拟镜像流水线边界、安装器测试和准确依赖许可证校验也均通过。GoReleaser 2.18.0 接受了发布配置。

标签工作流会独立重复这些检查，并在公开预发布版前构建、验证全部归档、原生软件包、SBOM、配方、安装器、发布元数据和校验和。
源码检查不提供新的真机虚拟机生命周期证据，也不代表镜像候选已发布。

## 安装或升级

从 [Barn 0.5.0 GitHub 发布](https://github.com/pgsty/barn/releases/tag/v0.5.0)
下载安装器与资产：

```bash
curl -fLO https://github.com/pgsty/barn/releases/download/v0.5.0/install.sh
chmod +x install.sh
BARN_VERSION=0.5.0 ./install.sh
barn version
barn doctor
```

同一预发布附带 Homebrew 配方与 amd64/arm64 DEB/RPM 软件包。
