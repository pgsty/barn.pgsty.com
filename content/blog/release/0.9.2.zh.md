**发布日期：2026-10-30。** Barn 0.x 版本通过 GitHub 预发布渠道分发。

Barn 0.9.2 将完整的 macOS 原生客机组件纳入 Apple Silicon 下载包与 Homebrew 安装。安装一个软件包即可创建 Linux 和 macOS 虚拟机，无需安装 Go 或 Xcode。

[安装 Barn](/zh/docs/start/installation/) · [下载 0.9.2](https://github.com/pgsty/barn/releases/tag/v0.9.2) · [源码发布说明](https://github.com/pgsty/barn/blob/v0.9.2/.github/releases/0.9.2.md)

## 变更

- Darwin arm64 归档包含同一源码提交构建的 `barn`、`barn-hosts-helper` 与原生应用包 `Barn.app`。三个可执行文件均使用 Developer ID 签名并共同提交 Apple 公证；App 已装订公证票据并通过 Gatekeeper 检查。
- `brew install pgsty/infra/barn` 一次安装 CLI、QEMU、helper 与原生 App，CLI 自动发现 Homebrew `libexec` 下的 App。macOS 客机要求 Apple Silicon、macOS 27+ 及已登录的图形桌面会话。
- helper 先签名，再将最终 SHA-256 嵌入 CLI；发行归档装配原生组件后，打包流程再次验证配对关系。
- `ssh`、`exec`、`mac ssh` 与 `mac exec` 执行远端命令时必须使用 `--`。SSH 将命令行交给客机 Shell，exec 保留独立参数；exec 中需要管道或重定向时，请显式使用 `sh -c`。
- Linux arm64/amd64 与 Intel macOS 继续提供 CLI 和 helper，通过 QEMU 运行 Linux 客机。

## 安装与使用

```bash
brew install pgsty/infra/barn
barn version

# Linux 客机
barn up
barn ssh
barn exec meta -- uname -a

# Apple Silicon / macOS 27+ 上的 macOS 客机
barn mac doctor
barn mac up mac1
barn mac open mac1
barn mac ssh mac1
```

首次创建 macOS 虚拟机需要下载 Apple 恢复镜像并准备可复用的基础系统，也可通过 `barn mac setup --ipsw PATH` 使用已有的兼容 IPSW。

## 升级

替换 App 前先停止运行中的 Mac 虚拟机，再执行 `brew update` 与 `brew upgrade pgsty/infra/barn`。磁盘与配置保留在 `~/.barn`，无需重建虚拟机。旧版 SSH/exec 脚本请补上 `--`，并将 exec 的程序名与参数分开传递。

下载安装器需显式指定 `BARN_VERSION=0.9.2`，因为 GitHub 的 `releases/latest` 不会选择预发布版。本次发布包含四平台归档、Linux DEB/RPM 软件包、SPDX 物料清单、校验和、安装器及生成的 Homebrew 配方；`release.json` 记录精确源码提交与锁定的构建工具版本。
